# Balance Flow - Demo Guide

## 🎯 Overview
Balance Flow is a secure productivity and burnout management web platform designed for college students. The system helps students manage tasks, track stress levels, analyze burnout risk, and generate adaptive workload plans.

## 📱 Features

### 1. Authentication
- **Login Page:** Secure email/password authentication with Google sign-in option
- **Sign Up Page:** Account creation with mandatory OTP verification
- Demo account pre-configured with sample data

### 2. Dashboard (Main Control Panel)
- Today's workload summary
- Real-time stress score meter
- Color-coded burnout risk indicator
- Weekly progress tracking
- Adaptive workload plan with calendar date selection
- Generates personalized task recommendations based on selected date

### 3. Add Task Page
- Professional table layout for task management
- Add, edit, and delete tasks
- Task fields: Title, Sub-deadline, Priority, Status, Notes
- Visual priority and status badges
- Sortable by priority

### 4. Burnout & Energy Analysis
- Burnout score, stress score, and energy level meters
- Weekly progress graph showing stress and energy trends
- Daily energy optimization (morning/afternoon/evening)
- Weekly energy optimization recommendations
- Burnout Buddy chatbot for guidance
- High-priority tasks with stress level indicators

### 5. Mental Health Recommendation
- Interactive questionnaire (4 questions):
  - How are you feeling today?
  - Sleep hours last night
  - Workload manageability
  - Current energy level
- Automatic stress level detection (Low/Medium/High)
- Color-coded stress meter
- Personalized recommendations based on responses
- Quick actions: Talk to Burnout Buddy, Adjust Workload

### 6. Task Dashboard
- Comprehensive task analytics
- Tasks grouped by priority (High/Medium/Low)
- Upcoming deadlines section
- Overall weekly completion percentage
- Visual progress tracking

### 7. Profile Settings
- View and edit user information
- Change password
- Dark mode toggle
- Secure logout with confirmation

## 🚀 Getting Started

1. **Login** using the demo credentials or create a new account
2. **Explore the Dashboard** to see your workload summary and adaptive plans
3. **Add Tasks** using the task management page
4. **Check Burnout Analysis** to monitor your stress and energy levels
5. **Take the Mental Health Check** for personalized recommendations
6. **View Task Dashboard** for comprehensive task analytics
7. **Toggle Dark Mode** in the top navigation or profile settings

## 💡 Tips
- Use the **Adaptive Workload Plan** calendar to plan future dates
- Take the **Mental Health Check** regularly to track stress levels
- Monitor the **Weekly Progress** graph to identify stress patterns
- Use **Dark Mode** for comfortable evening study sessions
- Check **Upcoming Deadlines** to stay on top of your tasks

## 🔒 Security
- All data is stored locally in your browser
- Passwords are managed securely
- OTP verification for new account creation
- Logout confirmation to prevent accidental sign-outs
